# Oak development instructions

Follow the current MamreTek central application conventions when available; otherwise use `docs/development-conventions.md` (version 1.3). Use React, strict TypeScript and Ant Design. Follow the Ant Design Pro UI reference described in `docs/ui-reference.md`. Resolve the external requirement/workflow record by the normalized `MamreTek/oak` origin. Requirements stay outside this repository.

Work through issue branches and pull requests. Preserve unrelated changes. Do not merge or deploy without explicit authorization. This is an isolated synthetic-data prototype: no real infrastructure, credentials, production data or newly implemented permission system. Keep API contracts, Mock handlers, tests and documentation consistent. Run lint, typecheck, tests and build before submitting a PR.
