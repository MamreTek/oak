# Oak 本期决定

- 2026-11-03，REQ-001：无既有 Oak 代码或后端，使用中央规范 1.2 的 React + TypeScript + Ant Design + Vite 和隔离 Mock；无需搭建 Go、数据库或基础设施。
- 本期完整闭环为发现 → 入库 → IP 分配 → 模拟装机 → 状态/审计。IDC 拓扑只读、IPv4 每池 16 个演示地址、每设备单业务 IP，是待真实需求确认的模型范围。
- 原型仅保留内存状态；刷新重置。装机/发现为查询驱动的有限时间模拟任务，不提供后台执行或持久队列。
- 新增认证和菜单/按钮/接口权限暂缓，页面明确缺少权限保护；未使用生产数据或真实设备。凭据仅有说明占位。
- 在公开仓库中只放重新编写的产品代码、通用规则快照和合成数据；不复制官方私有项目源码、原始需求资料或本机工作流记录。
- 主分支仅作最小 README 引导提交，并保护 PR、禁止强推/删除；实现通过 Issue 分支/PR 交付。不合并 PR、不部署生产。
- 2026-11-03，用户追加 UI 要求：采用中央规范 1.3，参考 Ant Design Pro 官方预览及其链接提交的布局、列表和表单结构，用现有 Ant Design 实现浅色后台框架、蓝色操作、标准查询与表格，不迁移 Umi 或引入整套脚手架。参考站登录页可达，但公开示例登录未进入后台；实际核验边界见 `ui-reference.md`。
- 2026-11-03，用户确认功能参考中的 CloudBoot 指云霁科技的 [CloudBoot／OSInstall](https://github.com/idcos/Cloudboot)，与 [Cobbler](https://github.com/cobbler/cobbler) 一起作为 Oak 产品分析及后续规划的正式功能参考。两者能力分别以官方仓库与文档核对，区分文档支持、实测结果和未验证项；参考对象确认不代表批准新增功能开发、接入真实设备、部署或复制代码及内容。后续如评估组件复用，按具体子项目、文件和第三方组件分别核对许可证。
- 2026-11-03，用户随后批准按上述参考完善镜像/模板、参数预览、预检、阶段日志和失败重试，并明确批准修正过时背景后更新公开 Issue #1。继续现有 issue/1 与 PR #2，使用不可变元数据版本和任务参数快照；计划为不可执行 JSON，所有规则及阶段为 Mock。镜像请求从旧固定枚举迁移至 ID/模板/主机名，契约同步为 v1.1 草案。模板不接收脚本，不引入参考项目组件。具体参考与限制见 `provisioning-reference.md`。
