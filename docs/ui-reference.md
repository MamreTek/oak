## 对比与修正

| 维度 | 原界面 | 本次修正 |
| --- | --- | --- |
| 布局与导航 | 深绿色品牌侧栏、英文副标题、居中限宽内容 | 浅色头部与可折叠侧栏，流式内容，灰底白卡，选中项沿用 Ant Design |
| 页头 | 宣传式标题、全大写英文分类、大量留白 | 面包屑、普通中文业务标题、简短说明和页面操作 |
| 字号与密度 | 多处 9–11px 小字与自定义表格字号 | 14px 正文、12px 次要信息、20px 页标题；表格 middle 尺寸，上下内边距通过 token 统一为 8px，双行次要文字行高 18px |
| 查询与操作 | 资产查询和新增混在页面上方 | 带标签的资产查询表单及查询/重置，新增/刷新放到列表工具栏 |
| 统计与图形 | 绿色装饰图标与自制分布条 | 标准 Statistic / Progress，数据仍来自统一 Mock API |
| 表单与详情 | 原有 Ant Design 弹窗、抽屉与表单 | 保留校验、提交/取消、确认和错误处理，统一主题尺度 |
| 原型说明 | Mock 与安全边界提示 | 保留常驻提示和场景工具，不将样式更新当成权限能力 |

## 必要业务差异

机架 U 位、IPv4 地址格、发现候选和装机任务日志保留专用视图，因为它们表达裸金属资源位置、地址占用和任务状态。周边导航、卡片、表格、表单与反馈使用相同后台样式。

采用现有 React + Ant Design 组件组合实现对应模式，不要求迁移到 Umi 或添加 ProComponents 依赖。业务接口、状态约束、审计和 Mock 隔离未调整。表格与机架视图在手机宽度内局部滚动，导航改为抽屉。

## 验证方式

运行 lint、strict typecheck、现有 API/界面行为测试和 build；界面测试补充资产查询重置结果。浏览器核验桌面查询/重置、创建/详情、发现与装机流程、错误恢复，及 390px 手机导航与整体宽度。最终结果与未完成项记录于 `verification.md`；测试通过不代表真实后端或生产安全验收。

## 装机流程深化

继续使用现有浅色导航、查询工具栏、表格、弹窗及详情抽屉。新增镜像/模板以标准 Tabs 和表格管理；复杂装机表单拆为“配置参数 → 预览与预检”，用 Descriptions 展示待提交参数、明确覆盖影响，再确认创建模拟任务。流程结构参考同一官方提交的[分步表单](https://github.com/ant-design/ant-design-pro/blob/2db826cb350e46206252197f416a0a22f2b9bbfe/src/pages/form/step-form/index.tsx)，仅采用步骤、参数确认和反馈模式，未复制代码或转账业务内容。

阶段和时间日志为装机业务所需的专用视图，沿用 Ant Design Steps、Table、Alert、Tag、Progress。本轮电脑控制工具未提供可用浏览器，Chrome 打开返回不可用；因此新增页面的桌面/手机视觉与真实浏览器交互尚未核验，不能沿用上轮截图作为本轮证据。RTL 自动化覆盖流程，但不替代视觉验收。

## 资源与配置管理深化

资源位置采用带父子行的标准表格与属性表单，保留原有机架 U 位视图。发现页以“认证配置”入口展开元数据表格；没有密码输入、显示或真实认证按钮。网段列表为第一层，点击后以面包屑和返回操作进入该网段 IP 表格。模板脚本使用普通文本编辑框、类型选择、基础检查反馈及保存新版本弹窗；不引入在线执行终端或第三方编辑服务。布局和操作沿用现有 Ant Design Pro 基线，不增加装饰性视觉。

额外参考站的无需登录访问失败，电脑控制清单仍没有浏览器，也未发现安全登录交接工具；没有取得其登录后页面或数据，未复制页面、品牌、内容或内部资料。内部网址和登录信息不在公开仓库内。实际浏览器与手机视觉核验仍是未完成项，域/RTL 测试仅验证原型规则与交互。
